# omarchyvr v0.1.0

Unofficial. Supports the Pimax Dream Air. Not affiliated with Pimax or Omarchy.

The first tagged release: one install from `git clone --recursive`, one password, then Play goes straight into SteamVR.

## Install

    git clone --recursive --branch v0.1.0 https://github.com/laughtt/omarchyvr.git
    cd omarchyvr && ./install.sh

Then the app's wizard: **System setup** (one password), reboot only if it says so, then **Play**. Details are in
[docs/INSTALL.md](../INSTALL.md); uninstalling is covered in [docs/UNINSTALL.md](../UNINSTALL.md).

## What is in it

- **The app (`omarchyvr-app`)**: one window for everything. It has an onboarding wizard, Ready checks with fixes,
  Play (SteamVR) and Work (the VR desk), settings switches, logs, and a problem report.
- **VR runtime**: Monado (fork `laughtt/monado`, tag `omarchyvr-v0.1.0`) with the Pimax Dream Air driver: 72/90 Hz
  direct mode, lens model, 6DoF inside-out tracking (Basalt), room anchor, eye tracking, controllers (in hand or
  always), camera hand tracking (Mercury models, fetched only on request), a recorder tap, and a SteamVR driver.
- **Desk**: WayVR (fork `laughtt/wayvr`, tag `omarchyvr-v0.1.0`). Screens in VR, gaze, the watch, presets, and
  passthrough.
- **Voice**: speech recognition runs on the processor by default (Parakeet). "Speech on graphics card" is an
  optional switch. Local AI (Lara router plus Qwen action model) or online.
- **Recording**: 30 fps with sound, started by voice or from the app.
- **Install system**: `./install.sh` and `./uninstall.sh`. Every system change and every file is in a manifest,
  originals are backed up and restored, and there is one root job per install and per uninstall.
- **NVIDIA patches** (three, for the headset's merged two-head mode) for the tested driver only. Pacman hooks
  re-apply them after driver updates and fall back to the stock module if a build fails.

## Requirements

| Item | Tested | Experimental | Unsupported |
|---|---|---|---|
| Distro | Omarchy (Arch) | other Arch-based | non-Arch |
| Compositor | Hyprland | Wayland compositors with DRM lease | X11 |
| GPU | NVIDIA RTX 4090 | other NVIDIA RTX (open modules); AMD, Intel (no patches) | NVIDIA without open-module support |
| NVIDIA driver | nvidia-open-dkms 610.57.04 | none | other versions run unpatched until tested |
| Headset | Pimax Dream Air | other Pimax models (read-only probe, "untested") | |

## Tested hardware

i9-14900KF, 64 GB, RTX 4090 (nvidia-open-dkms 610.57.04), kernel 7.2.5-omarchy, Hyprland (Lua config),
Pimax Dream Air on DisplayPort with its controllers, Steam with SteamVR.

## Known limits

- One tested NVIDIA driver version. Any other version runs without the patches: the left half shows in both eyes
  until that version is tested.
- First install builds everything from source: 45-90 minutes and about 40 GB of build space.
- The eye tracker's cold-start data is not in the public tree. Without it, eye tracking does not start (see
  docs/EYE.md).
- On a PC without the build packages, the installer asks once more, for pacman, before the build (with
  `--install-packages`).
- The Mercury hand models have no licence. They are never shipped, and are fetched from upstream only when you ask.
- The speech-model and ONNX Runtime download URLs are the obvious upstream ones. The tested PC got these files by
  hand, so the checksums decide: a mismatch is refused.
